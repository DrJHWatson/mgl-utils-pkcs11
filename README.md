## Description

Пакет предоставляет низкоуровневый доступ к токенам через библиотеку м интерфейсом PKCS11. На первом этапе запланирована реализация простой обертки вокруг этого API для более удобного использования внутри приложений на базе NodeJS.

## Installation

```bash
npm i -s @mgl-utils/pkcs11
```
